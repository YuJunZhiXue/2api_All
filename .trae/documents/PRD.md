# PRD: Nvidia API Gateway Management Dashboard

## 1. 产品概述
这是一个专为 Nvidia API 聚合网关设计的**超级管理员前端控制面板**。目标是让超级管理员 (LO) 能够直观、高效地管理几十上百个 Nvidia 免费 API Key，监控系统并发状态，以及管理下发的 Master Key 授权与配额。该面板必须展现出极致的**暗黑极简主义**与**工业控制级**的视觉压迫感，绝不使用平庸的“AI 模板”审美。

## 2. 核心用户体验目标
- **冷酷与绝对掌控**：UI 风格必须如同星际战舰的指挥舱（深色背景、高对比度的荧光绿/终端红点缀、几何线条、 monospace 字体）。
- **即时反馈**：Key 的状态（Active/Cooling/Dead）变化必须以最醒目的方式呈现。
- **无废话设计**：只保留最核心的增删改查与监控图表，拒绝任何形式的花哨与冗余。

## 3. 功能模块 (Functional Requirements)

### 3.1. 数据概览大盘 (Dashboard Overview)
- **活跃度指标**：当前可用的 API Key 数量 vs 已阵亡 (Dead) 数量。
- **并发状态**：显示当前 Redis 正在被锁定的并发连接数估算。
- **实时拦截与流量**：最近 24 小时处理的 Token 数量与成功拦截的 429/401 次数（需后续后端指标配合，前端先做占位与基础数据呈现）。

### 3.2. API Key 资源池管理 (API Key Pool)
- **密钥列表**：表格形式展示所有的 Nvidia API Key（由于后端已加密，前端只展示 ID、名称、权重、当前状态、添加时间）。
- **状态徽章**：
  - `Active` (闪烁的绿色小圆点)
  - `Cooling` (黄色的警告标识，代表正在 60s 冷却期)
  - `Dead` (红色的禁止标识，代表已被英伟达封禁，正被探针隔离)
- **新增密钥录入**：提供一个简洁有力的模态框（Modal），允许管理员一次性粘贴录入新的 Key，并设定其分配权重。

### 3.3. Master Key 鉴权管理 (Master Key Auth)
- **客户端分发**：生成用于下发给业务端的 Master Key。
- **限流与配额**：配置 RPM（每分钟请求）、TPM（每分钟 Token）以及硬性 Quota 配额（如 10,000,000 Tokens）。
- **用量追踪**：查看每个 Master Key 已消耗的 Quota，并提供一键封禁（Revoke）功能。

## 4. 视觉与美学规范 (Aesthetic Direction)
- **主题方向**：**Cyber-Industrial (赛博工业风)**
- **排版 (Typography)**：
  - 标题与强调数字：使用冷峻无情的无衬线字体（如 `Space Grotesk` 或 `Inter Tight`，辅以大写字母和加粗）。
  - 数据与代码：强制使用 Monospace 字体（如 `JetBrains Mono` 或 `Fira Code`），体现极客的绝对理智。
- **色彩空间 (Color Palette)**：
  - 背景层：极致深邃的黑 (`#0A0A0B`)。
  - 表面层与边框：细锐的深灰/碳灰色 (`#1A1A1C`, `#27272A`)。
  - 核心高光：用于数据与图表的**荧光冷绿** (`#00FF41`) 或**电网蓝** (`#00E5FF`)。
  - 致命警告：刺眼的**纯正血红** (`#FF003C`)，用于标示 Dead Keys 或系统熔断。
- **微动效 (Motion)**：
  - Hover 时有极短的 CRT 屏幕闪烁或代码字符跳动效果。
  - 拒绝缓慢、平滑的过渡，要求像机械开关一样干脆、清脆的反馈。

## 5. 后续迭代扩展
- 接入 WebSocket，实现 Redis 中并发锁流转的实时打点动画（让 LO 能直观看到数据洪流如何在不同 Key 之间被无缝转移）。
